Export Data
Export all calculated tables to Google Sheets or a spreadsheet tool of your choice.
📋 Paste into Google Sheets
  1. Click Copy to Clipboard below
  2. Open sheets.new to create a new sheet
  3. Click cell A1 and press ⌘V (Mac) or Ctrl+V (Windows)
  4. Done — data fills into columns automatically!
⬇️ Download as CSV
  1. Click Download CSV below
  2. In Google Sheets: File → Import → Upload
  3. Select the downloaded file and click Import data
